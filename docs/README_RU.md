## Материалы документации

[Скриншот архива](images/archive-synchronized.png): настоящий UI из браузерных тестов с синтетическим видео, три камеры воспроизводятся, у четвёртой пропуск. Он показывает интерфейс, не совместимость реальных камер. Публичного демо и дополнительных скриншотов нет; тесты с синтетическими камерами описаны в руководстве участия.

[Разработка и проверки](development.md) — сборка Docker и запуск исходников для участников проекта (на английском).
