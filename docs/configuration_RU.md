# Конфигурация

Скопируйте [`.env.example`](../.env.example) в `.env`; это настройки Compose. Применяйте изменения пересозданием контейнеров с теми же файлами и выбором образа; см. [установку](installation_RU.md#управление-запуском).

[Документация](README_RU.md) · [English](configuration.md)

| Переменная | Значение в `.env.example` | Назначение |
|---|---|---|
| `NVR_PORT` | `8080` | Порт приложения на хосте |
| `NVR_BIND` | `127.0.0.1` | Адрес приложения; `0.0.0.0` для LAN с входом |
| `WEBRTC_UDP_PORT` | `8189` | UDP-порт медиаданных WebRTC |
| `WEBRTC_HOST` | пусто | LAN с сетью хоста обнаруживает интерфейсы; bridge по умолчанию использует localhost. Поддерживаются явные IP/DNS-имена. |
| `DATA_DIR` | `./data` | Каталог хоста для SQLite и сохранённых настроек |
| `DEFAULT_RECORDING_PATH` | `./recordings` | Корень записей на хосте |
| `SEGMENT_SECONDS` | `600` | Целевая длительность сегмента в секундах |
| `MIN_FREE_SPACE_GB` | `5` | Резерв свободного места в GiB |
| `AUTH_USERNAME`, `AUTH_PASSWORD` | пусто | Необязательный вход в UI/API; задайте оба |
| `COOKIE_SECURE` | `false` | Secure cookie сессии; включите для HTTPS |
| `FORWARDED_ALLOW_IPS` | `127.0.0.1` | Доверенные IP reverse proxy для заголовков схемы Uvicorn |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `DEFAULT_LANGUAGE` | `en` | Начальный язык интерфейса: `en` или `ru` |
| `APP_TIMEZONE` | `UTC` | Начальный часовой пояс установки; сохранённое в UI значение приоритетнее |
| `NVR_IMAGE` | `vvbelousov/tuponvr:0.1.0` | Образ/версия приложения; пустое значение использует локальный образ исходников |
| `NVR_UID`, `NVR_GID` | `0`, `0` | Числовой пользователь контейнера; non-root требует доступных для записи каталогов |
| `WEBHOOK_URL` | пусто | HTTP(S) endpoint уведомлений; пустое значение отключает их |
| `WEBHOOK_TOKEN` | пусто | Необязательный Bearer token |
| `WEBHOOK_DEBOUNCE_SECONDS` | `60` | Длительность непрерывной неисправности до первого события |
| `WEBHOOK_COOLDOWN_SECONDS` | `600` | Минимальный интервал между новыми инцидентами одного объекта |

Изменяющие запросы браузера проверяют Origin. Reverse proxy должен сохранять исходный Host. Для HTTPS задайте `COOKIE_SECURE=true` и реальные доверенные IP прокси в `FORWARDED_ALLOW_IPS`. Не используйте `*`, когда недоверенные клиенты могут обращаться к приложению напрямую. См. [сеть](networking_RU.md).

Приложение запускает один процесс Uvicorn (`--workers 1`); второй может создать дублирующие процессы FFmpeg. База содержит пароли камер открытым текстом: защищайте `DATA_DIR` и резервные копии. Файлы SQLite создаются с правами `0600`. Структурированные события backend не содержат приватных URL и паролей; access logging Uvicorn отключён.

Для общего доступа используйте вход, вне доверенной LAN — HTTPS и Secure cookies. Сигнализация браузера проходит через `/api/media` на origin приложения. TCP 8889, 8554 и 9997 MediaMTX держите закрытыми; Compose не публикует их. См. [безопасность и миграцию](security-hardening_RU.md).

## Права контейнера

Root остаётся стандартным пользователем для совместимости bind mounts; FastAPI, FFmpeg и вызовам API MediaMTX он не требуется. Для non-root сначала создайте каталоги данных/записей с владельцем `NVR_UID`/`NVR_GID`, затем задайте эти числовые ID в `.env`. Прежним базам, настройкам и маркерам с владельцем root может понадобиться осознанная смена владельца. Не ослабляйте права глобально и не меняйте владельца NAS вслепую.

Стандартная установка использует bridge, убирает `NET_RAW` и запрещает новые привилегии. Необязательный Linux LAN overlay использует сеть хоста для обнаружения интерфейсов WebRTC. Privileged mode и Docker socket не нужны. Требуются доступные для записи каталоги данных/записей и место для временных файлов. Healthcheck образа проверяет `/health`; `/ready` отдельно проверяет MediaMTX.
